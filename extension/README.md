# 浏览器扩展使用说明

当前版本：`v1.0.0`

扩展支持 Edge 和 Chrome。它适合已经能够正常登录创量的操作人员，不包含登录、验证码或权限绕过能力。

## 安装

1. 打开 `edge://extensions` 或 `chrome://extensions`。
2. 开启“开发人员模式”。
3. 点击“加载解压缩的扩展”。
4. 选择本项目中的 `extension/` 文件夹。
5. 打开创量页面；扩展只对 `*.mobgi.com` 生效。

## 界面

扩展包含两个入口：

- 工具栏 popup：填写账户、短剧、商品库和素材目录后快速启动统一模式。
- 页面浮动面板：支持统一模式、多账户各自一剧、售卖策略、暂停和停止。

商品库和素材目录必须与平台名称完全一致。扩展不会把这些字段保存到本地。

## 统一模式

多个账户共用一部短剧。

1. 选择“统一模式”。
2. 填写账户 ID，支持逗号、空格或换行分隔。
3. 填写共用短剧名。
4. 填写商品库和素材目录。
5. 按需勾选“复用模板”和“售卖策略”。
6. 点击“开始”。

## 多账户（各自一剧）

1. 选择“多账户（各自一剧）”。
2. 在账户列表中一行填写一个账户 ID。
3. 在短剧列表中一行填写一部短剧。
4. 确认两个列表数量一致且顺序对应。
5. 填写商品库和素材目录。
6. 点击“开始”。

推广产品、创意素材和落地页会按账户分别设置。

## 运行控制

- “暂停”会暂停大多数等待和页面轮询。
- “继续”恢复执行；部分人工接管完成后面板会自动收起。
- “停止”会立即中断当前等待，但不会回滚已经完成的平台操作。
- “复制”可以复制当前面板日志。
- 收起按钮会把面板变成页面右下角悬浮球。

## 人工接管场景

遇到以下情况时，扩展可能暂停并等待人工处理：

- 搜索到多个同名短剧。
- 某个账户的素材搜索结果为 0。
- 页面新版 UI 无法自动识别账户。
- 落地页同名但属于其他账户。
- 售卖策略存在歧义或格式不符合预期。

处理页面后点击“继续”。详细说明见 [故障排查](../docs/troubleshooting.md)。

## 售卖策略

勾选“启用售卖策略（付费短剧）”后选择 `.xlsx` 文件。扩展会在浏览器内解析文件，并按账户和短剧名匹配策略。

详见 [售卖策略说明](../docs/strategy-xlsx.md)。

## 隐私

- 不在代码中保存真实账户、个人姓名或固定商品库。
- 不保存本次输入的账户、短剧、商品库和素材目录。
- 不向其他第三方服务发送策略文件。
- 不得在 Issues、日志或截图中暴露账号和业务数据。

完整说明见 [隐私与合规](../docs/privacy-and-compliance.md)。
