# 售卖策略 XLSX 说明

售卖策略为可选能力，适用于付费短剧。

## 支持的列

工具会根据表头识别：

- 媒体账户或账户 ID。
- 策略名称。
- 起充集数。
- 单集价格。
- 最低充值。
- 可选短剧名列。

## 匹配规则

1. 优先使用“账户 + 短剧名”精确匹配。
2. 短剧名存在包含关系时尝试容错匹配。
3. 缺少短剧名列时按账户兜底。
4. 同一账户存在多个不同策略且没有短剧名列时，会产生歧义。

## 上传处理

如果文件包含额外的“短剧名”辅助列，扩展会在上传前移除该列，使文件保持平台要求的模板结构。

## 隐私

- 策略文件只在浏览器本地读取。
- 文件内容会通过正常页面流程提交给当前目标平台。
- 不要把真实策略表提交到 Git。
- 不要在其他网站上传或粘贴策略内容。

## 失败处理

如果出现“失败详情”或被其他账户已选策略占用，先按页面提示人工处理，再点击“继续”。
