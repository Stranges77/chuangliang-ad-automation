# 浏览器扩展完整使用说明

## 1. 适用场景

扩展适用于：

- 已手动登录创量。
- 有目标媒体账户的访问权限。
- 需要减少新建广告草稿时的重复点击。
- 愿意在执行结束后人工复核预览。

## 2. 安装

1. 打开 `edge://extensions` 或 `chrome://extensions`。
2. 开启开发人员模式。
3. 点击“加载解压缩的扩展”。
4. 选择 `extension/` 目录。
5. 回到创量页面并刷新一次。

## 3. 首次检查

点击扩展图标，再点击“自检”。如果显示页面实际运行的版本号，说明注入成功。

如果失败：

1. 确认当前页面域名是 `*.mobgi.com`。
2. 刷新创量页面。
3. 回到扩展管理页面点击扩展卡片的刷新按钮。
4. 检查站点访问权限。

## 4. 必填项

每次运行都需要填写：

- 账户 ID。
- 短剧名。
- 商品库名称。
- 素材目录名称。

商品库和素材目录必须与平台上的显示名称一致。扩展不会持久化这些字段。

## 5. 统一模式

适用于一个广告下的多个账户使用同一部短剧。

1. 打开“统一模式”。
2. 输入账户 ID。
3. 输入共用短剧名。
4. 选择是否复用模板。
5. 按需启用售卖策略。
6. 点击“开始”。

## 6. 多账户（各自一剧）

适用于一个广告关联多个账户，每个账户使用不同短剧。

1. 打开“多账户（各自一剧）”。
2. 账户列表一行一个。
3. 短剧列表一行一个。
4. 保持两个列表数量相同、顺序对应。
5. 点击“开始”。

## 7. 执行结果

扩展最后执行“生成预览广告”，不会自动点击最终提交审核。

运行结束后请检查：

- 账户。
- 推广产品。
- 售卖策略。
- 素材数量和顺序。
- 落地页。
- 广告基础信息。

## 8. 控制按钮

- 暂停：停止推进新的页面动作，并暂停可中断的等待。
- 继续：恢复流程。
- 停止：中断当前等待和后续步骤，不回滚已完成操作。
- 复制：复制当前面板日志。
- 收起：切换到悬浮球。

遇到需要人工处理的情况时，先完成页面操作，再点击“继续”。
