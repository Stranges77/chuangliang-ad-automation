# 多账户（各自一剧）模式

该模式用于一个广告关联多个账户，每个账户使用不同短剧。

## 输入

账户列表和短剧列表必须逐行对应：

```text
账户列表       短剧列表
10000001   →   示例短剧 A
10000002   →   示例短剧 B
10000003   →   示例短剧 C
```

数量不一致时扩展不会启动。

## 按账户处理的字段

- 推广产品。
- 售卖策略。
- 创意素材。
- 落地页。

## 校验

- 账户勾选后回读“已选 N”。
- 切换账户后等待弹窗加载完成。
- 删除该账户旧的推广产品、素材或落地页。
- 无法确定账户或同名内容时暂停。

## 风险

该流程会产生更多页面操作。停止或失败时，已经执行的账户配置不会自动回滚，必须人工检查。
