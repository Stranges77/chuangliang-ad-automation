# 故障排查

## 扩展图标点击无反应

1. 确认当前页面是创量页面。
2. 刷新页面。
3. 到扩展管理页面点击刷新按钮。
4. 检查站点访问权限。
5. 点击扩展的“自检”。

## 浮动面板消失

刷新平台页面。面板重新注入后，再检查当前广告状态。

## “更改”按钮点不到

查看面板日志中的候选元素、坐标和当前弹窗。平台可能修改了按钮结构，需要更新源码中的定位策略。

## 账户“已选 N”数量不对

扩展会尝试重新勾选。若仍不正确：

1. 点“停止”。
2. 手动清空账户选择。
3. 重新开始。

## 同名短剧

扩展会暂停。手动选择正确剧集后点击“继续”。

## 素材搜索为 0

确认素材目录、短剧关键词和账号权限。补传素材后点击“继续”，扩展会重新搜索。

## 素材目录被重置

搜索操作可能触发筛选区重渲染。扩展会尝试重新选择配置的素材目录并重新搜索。

## 落地页不可选

同名落地页可能属于其他账户或已经是使用状态。先人工确认对应账户下的落地页，再继续。

## 售卖策略不匹配

检查账户 ID、短剧名和列名。必要时增加“短剧名”辅助列，避免同一账户的多条策略产生歧义。

## Python 版报错

查看：

- 终端输出。
- `logs/run_*.log`。
- `logs/error.png`。

先运行 `python scripts/check_release.py` 排除源码和版本结构问题。
