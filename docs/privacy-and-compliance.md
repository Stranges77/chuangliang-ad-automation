# 隐私与合规说明

## 数据范围

扩展会读取当前页面中的账户、短剧、商品、素材、落地页和售卖策略信息，用于完成用户主动触发的广告草稿操作。

扩展不会主动向外部第三方服务发送业务数据，但页面操作本身会向创量平台提交用户选择的内容。

## 本地保存

- 扩展不保存账户、短剧、商品库和素材目录。
- Python 版的 `profile/` 保存登录态。
- Python 版的 `logs/` 保存日志和错误截图。
- 这些目录已加入 `.gitignore`。

## 禁止提交

不得提交：

- Cookie、Token、密码。
- 真实账户 ID 和账户清单。
- 客户、投手或公司内部姓名。
- 真实短剧、素材和落地页数据。
- 真实售卖策略文件。
- 未脱敏的平台截图。

## 使用责任

使用者应确认：

- 自己拥有账户和数据的操作权限。
- 自动化行为符合平台协议和公司制度。
- 自动化投放符合广告、数据、隐私和网络安全相关要求。
- 最终广告内容已经人工复核。

本项目不构成法律意见，也不保证任何特定平台允许自动化操作。
