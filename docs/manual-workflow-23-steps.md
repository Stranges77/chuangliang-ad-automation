# 23 步手工流程基线

本文件把最初的人工操作流程整理为纯文本，便于维护。扩展现在使用组合步骤，Python 版仍保留 23 个 `step_XX` 方法。

| 步骤 | 操作 |
|---:|---|
| 1 | 打开广告界面，点账户“更改” |
| 2 | 清空已选账户，再点“清空” |
| 3 | 打开批量添加或导入账户 |
| 4 | 输入账户 ID 并确定 |
| 5 | 选择账户并确定 |
| 6 | 点“复用”模板 |
| 7 | 打开广告创意“编辑” |
| 8 | 修改已选产品 |
| 9 | 清除旧短剧 |
| 10 | 清空搜索框并输入新短剧名 |
| 11 | 等待搜索框可用并搜索 |
| 12 | 选择匹配短剧；同名时人工判断 |
| 13 | 确定产品并保存广告基本信息 |
| 14 | 打开创意素材“选择素材” |
| 15 | 清空当前素材 |
| 16 | 批量添加视频 |
| 17 | 清空素材搜索框 |
| 18 | 搜索素材并全选前两页 |
| 19 | 乱序三次并确定素材 |
| 20 | 打开落地页“添加” |
| 21 | 搜索目标落地页 |
| 22 | 选择落地页并确定 |
| 23 | 生成预览广告，人工检查 |

## 与当前扩展的关系

扩展把上述动作组合为：

1. 改账户。
2. 清空已选账户。
3. 搜索并勾选账户。
4. 确认账户。
5. 复用模板。
6. 编辑广告信息。
7. 按规则设置推广产品。
8. 设置售卖策略。
9. 保存广告基本信息。
10. 按规则设置创意素材。
11. 按规则设置落地页。
12. 生成预览广告。

“23 步”描述的是手工业务节点，不是扩展内部函数数量。
